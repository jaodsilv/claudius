# Naming Plugin for Claude Code and Claude Cowork

## Description

This plugin provides a simple and efficient way to name things in Claude Code and Claude Cowork.

## Usage

```markdown
/naming:prompt
<prompt>
  {{PROMPT}}
</prompt>
```

## Current funcitonalities

- Naming Prompts for Claude Console: `/naming:prompts-for-claude-console <prompt>{{PROMPT}}</prompt>`

## Future funcitonalities

- Naming Agents: `/naming:agents <prompt>{{PROMPT}}</prompt>`
- Naming Commands: `/naming:commands <prompt>{{PROMPT}}</prompt>`
- Naming Skills: `/naming:skills <prompt>{{PROMPT}}</prompt>`
- Naming Projects: `/naming:projects <prompt>{{PROMPT}}</prompt>`
- Naming Anything: `/naming:anything <prompt>{{PROMPT}}</prompt> <type>{{TYPE}}</type>`
